# Migraciones de Base de Datos con TypeORM y NestJS

Un proyecto de software va evolucionando en una ventana de tiempo y de forma progresiva. Si hacemos bien las cosas utilizamos versionamiento de código, pero también es muy importante realizar lo que podríamos llamar un versionamiento de la base de datos. Es decir, debemos tener un mecanismo que nos permita ajustar el esquema de la base de datos a medida que nuestro modelo evoluciona, agregando o cambiando parámetros.

Cuando tenemos una base de datos en un estado particular y debemos realizar un ajuste, debemos ejecutar lo que llamamos una _migración_. Es decir, realizamos un ajuste en la base de datos y de esta forma no tenemos que borrar y crear una nueva base de datos, lo que sería impensable además, en un entorno productivo con miles de datos reales.

En este artículo vamos aver de forma muy concisa como podemos trabajar con migraciones en TypeORM y NestJS.
